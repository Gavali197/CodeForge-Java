A Linked List is a linear data structure, but unlike arrays, 
its elements are not stored in contiguous (side-by-side) memory locations.
Instead, it works like a scavenger hunt 
where each clue tells you exactly where to find the next one.


How It Works: The "Node"
The building block of a linked list is called a Node. Every node contains two distinct parts:

Data: The actual value you want to store (a number, a string, an object).

Next Pointer (or Reference): A link that points to the memory address of the very next node in the sequence.

The first node is called the Head (your starting point). The last node's pointer is set to Null (signaling the end of the list).



The 3 Main Types
Singly Linked List: Nodes point only forward to the next node.

Doubly Linked List: Nodes have two pointers (Next and Previous), allowing you to traverse forward and backward.

Circular Linked List: The last node points back to the Head instead of pointing to Null, creating a continuous loop.
